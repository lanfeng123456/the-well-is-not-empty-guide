# THE WELL IS NOT EMPTY Guide

An independent, evidence-aware guide for **THE WELL IS NOT EMPTY**, built with Next.js and TypeScript.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run typecheck
npm run build
npm run audit
```

The production site uses `https://thewellisnotempty.com`. Keep `NEXT_PUBLIC_SITE_URL` set to this origin in Vercel so the site emits matching canonical URLs, an indexable robots policy and a populated sitemap.
