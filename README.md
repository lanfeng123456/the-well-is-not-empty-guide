# THE WELL IS NOT EMPTY Guide

An independent, evidence-aware guide for **THE WELL IS NOT EMPTY**, built with Next.js and TypeScript.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run typecheck
npm run build
npm run audit
```

Set `NEXT_PUBLIC_SITE_URL` to the final HTTPS origin in production so the site emits canonical URLs, an indexable robots policy and a populated sitemap.
